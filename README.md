# TutuBot 分发资源库

本仓库仅用于托管 TutuBot 的 Release 资产（Windows/Framework/Shell 安装包），供 Docker 镜像构建与用户下载使用。

**源码位于私有仓库，不对外公开。**

## 下载

请到 Releases 页面下载对应版本的资产：

- `TutuBot.Shell.zip` — Linux Shell 运行包（Docker 镜像使用）
- `TutuBot.Framework.zip` — Framework 运行包
- `TutuBot.Shell.Windows.Node.zip` — Windows 一键运行包（含 Node 与 QQ）
- `TutuBot.Shell.Windows.OneKey.zip` — Windows 精简包
